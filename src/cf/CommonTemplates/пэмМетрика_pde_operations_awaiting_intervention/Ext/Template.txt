// Лейблы: flow_name, direction (incoming/outgoing)
//
// Единица измерения - операция, завершившаяся ошибкой и исчерпавшая число попыток: подсистема

// сообщение, отправке подписчику - пара «сообщение, подписчик».
//
// Отбор является отрицанием условия «попытки остались», по которому отбирает операции метрика
// pde_operations_awaiting_retry, поэтому множества двух метрик не пересекаются, а вместе
// покрывают все записи регистров текущего статуса в статусах ошибки.
//
// По каждому активному потоку данных выводится нулевая строка, поэтому метрика не исчезает
// из ответа. Поток данных записи рассылки определяется через очередь исходящих сообщений;
// запись, для которой поток определить не удалось, выводится с меткой flow_name="unknown".
